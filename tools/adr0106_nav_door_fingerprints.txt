# One line per RUNTIME record produced by tools/adr0106_nav_door_scan.awk over
# the reaching set in tools/adr0106_nav_reach_symbols.txt:
#
#     <file>|<enclosing_fn>:<symbol>
#
# Line numbers are deliberately NOT part of the fingerprint (same convention as
# the ADR-0098 opener fingerprints) so unrelated edits that shift lines in
# serve.rs do not red the gate. What IS pinned is WHO calls WHAT — the only
# thing that matters for "can this path reach NAV filing".
#
# `#emitter-def` records pin the set of NAV wire-body emitters in nav_xml.rs
# (seven today). An eighth cannot land without this file changing.
#
# To change this file legitimately you must ALSO update
# adr0106_nav_door_registry.txt (if a new door appeared) or
# adr0106_nav_reach_symbols.txt (if a new waypoint appeared). A diff here with
# neither of those touched is the review signal.
